# User Settings File

## File Location

The settings file to use is specified in the login window.

* If you choose a settings file with your username (Eg: AppCOM-myname.ini) the file is used from wherever it resides.

* If you choose a settings file with someone else's username (Eg: AppCOM-notmyname.ini) from somewhere other than your AppCOM folder, the file is copied to your AppCOM folder and used from there.

## Saving

To save a settings file, use the *Tools - Save User Settings* menu item.
